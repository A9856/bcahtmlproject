CSS Position Property Practical

1. position: static

Static is the default position. Element normal document flow mein rahta hai.

STATIC BOX

2. position: relative

Relative element apni original position ke according move hota hai.

CSS mein top aur left ko uncomment karke dekhein.

3. position: absolute

Absolute element nearest positioned parent ke according position hota hai.

PARENT
ABSOLUTE BOX

4. position: fixed

Fixed element browser viewport ke according fix hota hai.

CSS mein fixed-box ke andar position, bottom aur right ko uncomment karein.
