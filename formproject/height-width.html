CSS Height & Width Properties

1. height

Height property element ki fixed height set karti hai. Is box ki height 150px hai.

2. min-height

min-height element ki minimum height set karta hai. Is box ki minimum height 150px hai. Agar content kam hai tab bhi box 150px se chhota nahi hoga.

3. max-height

max-height element ki maximum height set karta hai. Is box ki maximum height 150px hai. Agar content bahut zyada hai to box 150px se bada nahi hoga. Extra content ke liye scrollbar aa sakta hai.
